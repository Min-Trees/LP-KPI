# LP-KPI

Hệ thống quản lý và đánh giá KPI cho nhân viên.

## Tech Stack

- **Frontend**: React + TypeScript + Vite
- **Backend**: Firebase (Firestore, Authentication)
- **Styling**: Tailwind CSS

## Getting Started

1. Clone repository
2. Install dependencies:

```bash
npm install
```

3. Copy `.env.example` to `.env` and configure Firebase credentials

4. Start development server:

```bash
npm run dev
```

## Features

- Quản lý KPI theo kỳ (tháng/năm)
- Tự động tính điểm và xếp loại
- Phê duyệt KPI hàng loạt
- Báo cáo và xuất Excel
